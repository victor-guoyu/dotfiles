## as part the installation process, you need to git clone tmux package manager first (tpm)

git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

## in addition, you'll need nerd font install with the following brew command

brew install --cask font-code-new-roman-nerd-font

After installation, make sure to `ctl + ]` and `shift + i` to reload all the tmux plugins
